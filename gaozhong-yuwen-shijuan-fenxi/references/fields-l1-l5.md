# 五层字段定义

编码一份试卷时，逐设问登记 L1 至 L5。字段取值必须从本文件的词表中选择，不临时造词。同一现象在不同设问间必须用同一表述，否则频次统计失真。

## L1 基础属性

| 字段 | 说明 | 取值 |
|---|---|---|
| 题目编号 | 唯一标识 | `卷别-年份-题号`，如 `新课标Ⅰ-2024-8①` |
| 卷别 | 试卷来源 | 新课标Ⅰ、新课标Ⅱ、全国甲、全国乙、自主命题（省份名） |
| 年份 | 命题年份 | 四位年份 |
| 是否新高考 | 是否进入新高考模式 | 是、否 |
| 板块 | 所属板块 | 现代文阅读Ⅰ、现代文阅读Ⅱ、古代诗文阅读、语言文字运用、名篇名句默写 |
| 题型 | 作答形式 | 选择题、限制作答题、采点作答题 |
| 分值 | 试卷标注的实际分值 | 数字，不换算 |
| 板内占比 | 该分值占所属板块总分的比例 | 百分比 |
| 全卷占比 | 该分值占非作文部分总分的比例 | 百分比 |

题型三分是统计口径的基础：

- 选择题：唯一答案，全对给分
- 限制作答题：默写填空、文言翻译，逐点给分，答案高度确定
- 采点作答题：简答、分析、赏析、探究、语用主观、图文转换

默写与翻译必须从选择题和采点作答题中分离出来单独统计，否则默写的高得分率会污染选择题难度判断。

## L2 内容属性

| 字段 | 说明 | 取值 |
|---|---|---|
| 文本类型 | 阅读材料的类别 | 信息类文本、文学类文本、文言文、古代诗歌、语用材料 |
| 体裁 | 具体文体 | 论述文、实用类、非连续性文本、小说、散文、戏剧、史传、论说文、杂记、诗、词、曲 |
| 选材来源 | 材料的出处类型 | 报刊、学术论文、专著、文学期刊、官方文献、原创改编 |
| 作者国别 | 作者国籍 | 中国、外国 |
| 作品年代 | 所涉文本的年代 | 古代、现代、当代 |
| 文本组织 | 单文本还是多文本 | 单文本、群文组合 |
| 篇幅 | 文本字数 | 数字 |
| 教材关联 | 与统编教材的关联方式 | 显性关联、隐性关联、无关联 |

教材关联分两级登记：

- 显性关联：直接考查教材内的篇目、作家、单元主题，或默写篇目出自教材
- 隐性关联：考查的能力点对应教材单元学习任务或学习任务群，但不直接指向某篇课文

教材基准为统编版高中语文必修上下册与选择性必修上中下册。默写篇目核对以教材要求背诵篇目为准。

## L3 能力与素养

| 字段 | 说明 | 取值 |
|---|---|---|
| 考点 | 具体的知识与能力点 | 见下方考点词表 |
| 指令动词 | 题干中要求作答的动作 | 概括、分析、赏析、说明、探究、评价、比较、推断、梳理、拟写、翻译、补写 |
| 认知层级 | 题目要求的思维水平 | 识别确认、理解转述、推断判断、分析综合、鉴赏评价、探究创新 |
| 情境类型 | 课程标准的三类情境 | 个人体验情境、社会生活情境、学科认知情境 |
| 实践活动 | 课程标准的三类语文实践活动 | 阅读与鉴赏、表达与交流、梳理与探究 |
| 活动细类 | 实践活动下的具体指向 | 见下方活动细类词表 |
| 考查要求 | 高考评价体系的四翼 | 基础性、综合性、应用性、创新性 |

考点与认知层级必须分列两栏。记录"考查比喻"是记录考点，记录"考查鉴赏能力"是记录认知层级，两者不合并，也不互相替代。

### 考点词表

信息类文本：信息筛选整合、概念理解、文意推断、论证分析、材料比较、观点评价

文学类文本：内容概括、形象分析、语言赏析、手法鉴赏、结构作用、主旨探究、意蕴挖掘

文言文：实词含义、虚词用法、断句、文化常识、文意概括、句子翻译

古代诗歌：形象意境、语言风格、表达技巧、思想情感、比较鉴赏

名篇名句默写：直接默写、情境化默写

语言文字运用：成语词语、语病辨析、语句衔接、标点符号、修辞效果、语段压缩、句式变换、图文转换、补写句子、仿写改写

### 活动细类词表

阅读与鉴赏：整体感知、信息提取、理解阐释、推断探究、赏析评价

表达与交流：叙述表现、陈述阐释、解释分析、介绍说明、应对交流

梳理与探究：积累整合、筛选提炼、归整分类、解决问题、发现创新

### 情境类型判定

- 个人体验情境：学生个体独立开展的语文实践，如文学作品阅读中的情感体验、尝试不同阅读方法、创作文学作品
- 社会生活情境：校内外具体社会生活中的语文实践，强调交际对象、目的与表达方式
- 学科认知情境：探究语文学科本体问题，如文体知识、语言规律的探究

不把"图文结合""跨文本互证""情境化任务"当作情境类型，这些是呈现形式，记入其他字段。

## L4 命题技术

### 选择题专用

| 字段 | 说明 | 取值 |
|---|---|---|
| 题文对应位置 | 选项信息在原文的落点 | 句内、句间、段内、跨段、全文整合 |
| 选项改写方式 | 原文到选项的加工动作 | 同义替换、概括压缩、语序调整、增补限定、概念替换、逻辑关系改写 |
| 正确项改写幅度 | 正确项与原文的差异程度 | 直接转述、小幅改写、大幅整合 |
| 设误类型 | 错误项的设错手法 | 见下方八类 |
| 干扰项吸引力 | 是否有作答数据支撑 | 有数据（填选择率）、无数据 |

设误八类：偷换概念、张冠李戴、无中生有、以偏概全、强加因果、混淆时态模态、曲解文意、答非所问。

### 通用

| 字段 | 说明 | 取值 |
|---|---|---|
| 限定语强度 | 题干限定条件的约束程度 | 强限定、弱限定、无限定 |
| 题干要素 | 题干的构成成分 | 情境背景、指令动词、限定范围、赋分，逐项标注是否具备 |
| 答案要点结构 | 参考答案的构成 | 要点数量、单点分值、要点类型、有无层级差 |
| 要点类型 | 要点的属性 | 内容要点、手法术语、分析论证、表达效果、情感态度、观点评价 |
| 评分标准形态 | 评分依据的方式 | 采点给分、关键能力分层、等级描述、SOLO分层、开放评分、未提供 |
| 开放度 | 答案的确定性 | 答案唯一、多解并列、完全开放 |
| 文本依赖度 | 答案能否完全从文本推出 | 高（信息自足）、中、低（需外部知识） |

答案要点结构与评分标准形态只能依据用户提供的参考答案与评分细则登记。材料中未提供时记 `未提供`，不凭经验填充。

## L5 测量属性

| 字段 | 说明 | 取值 |
|---|---|---|
| 难度值 | 官方公布的难度系数 | 数字，无则记 `未提供` |
| 区分度 | 官方公布的区分度 | 数字，无则记 `未提供` |
| 整题得分率 | 该题平均得分除以满分 | 百分比 |
| 单点得分率 | 单个采分点的得分比例 | 百分比，仅在有评分细则时登记 |
| 空答率 | 未作答比例 | 百分比 |
| 满分率 | 得满分比例 | 百分比 |
| 高低分组差异 | 高分组与低分组在该题的得分差 | 数字 |

公开试卷通常不公布难度值与区分度。拿不到时不得用推断值填充，改用结构难度可及性作为替代指标：

| 替代指标 | 说明 | 取值 |
|---|---|---|
| 作答负荷 | 所需书写量与思维容量的匹配 | 低、中、高 |
| 文本依赖度 | 与 L4 同项，此处用于难度归因 | 高、中、低 |
| 模板有效性 | 能否靠既有答题套路作答 | 低、中、高 |
| 知识点交锋密度 | 单一设问涉及的考点数量 | 数字 |

替代指标只能支撑"结构难度"层面的判断，不能替代难度值与区分度，报告中必须标注为推断。

## 编码一致性

同一份试卷由两人独立编码时，比对以下字段的一致率：考点、认知层级、情境类型、实践活动、设误类型、评分标准形态。

一致率低于 80% 的字段需要回到本文件补充判定规则后再编码，不直接采用首次编码结果。

## 覆盖空缺

编码完成后另行登记该卷未涉及的常考考点。空缺本身是有效信息：未考文言虚词、未考语病辨析、未考标点符号，都说明该卷的考查侧重。
