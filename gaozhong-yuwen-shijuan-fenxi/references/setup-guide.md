# 环境与依赖说明

本 Skill 不使用任何第三方服务，无 MCP、无 API、无账号、无凭据需求，全程不联网。依赖仅两项：本机 Python 运行环境，以及对用户所提供文件的只读访问权限。

启动前运行只读环境检查：

```bash
python scripts/check_environment.py --capability 试卷编码 --capability 答卷比对
```

按需传入本次请求涉及的功能。检查只读取状态，不修改配置、不安装、不登录、不联网（除非显式加 `--network`，本 Skill 不需要）。

## 依赖一：python-runtime

- 用途：运行输入检查、环境检查与数据表生成脚本
- 支持版本：Python 3.10 及以上
- 支持系统：Windows、macOS、Linux
- 官方主页：https://www.python.org/
- 官方文档：https://docs.python.org/3/
- 官方下载地址：https://www.python.org/downloads/
- 登录网址：不需要
- Token/Key/OAuth 入口：不需要
- 登录后路径：不需要
- 权限与 scope：无，仅使用标准库
- 配置步骤：
  1. 从 https://www.python.org/downloads/ 下载 3.10 及以上版本
  2. 安装时勾选 Add Python to PATH（Windows）
  3. 重开终端，运行 `python --version` 确认版本
- 凭据存储：不涉及，脚本不读取任何环境变量与凭据
- 验证方式：`python scripts/check_environment.py --capability 试卷编码` 返回 `ready`
- 版本不符处理：返回 `unavailable`，报 `version_incompatible`，升级 Python 后重检
- 轮换和撤销：不适用，无凭据
- 核验日期：2026-09-12

标准库路径解析说明见 https://docs.python.org/3/library/pathlib.html。脚本使用 `pathlib` 处理路径，不使用平台专有写法。

## 依赖二：material-files

- 用途：读取用户提供的试卷与答卷文件
- 支持版本：不限定，取决于文件格式
- 支持系统：Windows、macOS、Linux
- 官方主页：https://www.python.org/
- 官方文档：https://docs.python.org/3/library/pathlib.html
- 官方下载地址：不适用
- 登录网址：不需要
- Token/Key/OAuth 入口：不需要
- 登录后路径：不需要
- 权限与 scope：只读访问用户明确提供的文件路径
- 配置步骤：
  1. 把试卷与答卷文件放到可读目录
  2. 在对话中提供文件路径或直接上传
  3. 确认文件格式属于下方支持列表
- 凭据存储：不涉及
- 验证方式：`python scripts/check_inputs.py <试卷路径>` 返回 `ready` 或 `partial`
- 权限不足处理：返回 `unavailable`，提示文件被占用或权限不足，请用户调整后重试
- 轮换和撤销：不适用。本 Skill 不复制、不留存文件副本，分析结束后不留任何原文件拷贝
- 核验日期：2026-09-12

### 支持的文件格式

试卷：

| 格式 | 扩展名 | 说明 |
|---|---|---|
| PDF（含文字层） | .pdf | 直接提取文本 |
| PDF（扫描件） | .pdf | 缺文字层时报 `no_text_layer`，需先 OCR 或改传图片 |
| 图片 | .jpg .jpeg .png .webp .bmp .tif .tiff | 由模型读取图像内容 |
| Word | .docx | 提取文本 |
| 纯文本 | .txt .md | 直接读取 |

答卷：

| 格式 | 扩展名 | 说明 |
|---|---|---|
| 扫描图、照片 | 同上图像格式 | 手写内容由模型识别，字迹不清处标记待确认 |
| 电子文本 | .txt .md .docx | 打字版答卷、答题卡导出文件 |
| 表格 | .xlsx .csv | 需含题号与得分列；无逐题痕迹时降级为 C 级证据 |

## 环境状态与路由

| 状态 | 含义 | 下一步 |
|---|---|---|
| ready | 依赖与当前请求所需文件均可用 | 跳过配置引导，直接进入正常流程 |
| partial | 核心流程可用，部分材料缺失 | 进入受限流程，按证据等级标注结论 |
| needs_setup | Python 版本不符或试卷文件缺失 | 只展示缺失项的配置步骤，完成后重检 |
| unavailable | 文件不可读、格式不支持或版本不兼容 | 说明原因，给恢复步骤与降级方案 |

已通过的检查项不重复引导。重检时只报告状态变化与仍未满足的项目。

## 功能降级

| 功能 | 失败条件 | 降级方式 | 限制标注 | 恢复方式 | 停止条件 |
|---|---|---|---|---|---|
| 试卷文本提取 | PDF 无文字层或文件损坏 | 请用户提供可读版本，或改传图片 | 基于用户提供的替代材料 | 提供含文字层的文件 | 无法获得任何可读内容 |
| 手写答卷识别 | 字迹模糊、涂改严重、跨区书写 | 标记为待确认并列出，请用户确认 | 该部分证据等级为未验证 | 用户确认或提供更清晰版本 | 关键内容无法辨认且用户无法确认 |
| 采分点判读 | 未提供评分细则 | 只判要点方向是否命中，不给精确分 | 缺评分细则，结论为部分验证 | 提供评分细则 | 无任何评分依据且用户要求精确判分 |
| 难度与区分度 | 试卷未公布相关数据 | 改用结构难度可及性替代指标 | 替代指标，证据等级为推断 | 提供作答统计数据 | 用户要求官方难度值而数据不可得 |
| 数据表生成 | xlsx 写入失败或磁盘权限不足 | 以 Markdown 表格输出结构化内容 | 文件未生成 | 检查写入权限后重试 | 用户要求必须交付 xlsx 且无法生成 |
| 报告文件生成 | 输出目录不存在或不可写 | 直接在对话中输出报告全文 | 报告未落盘 | 指定可写目录 | 用户要求文件形式交付且无可用目录 |

降级后保留已完成部分，标注未完成范围与证据等级，不用推测结果填充。

## 不支持的场景

- 非语文学科试卷：本 Skill 的字段词表与考点分类仅适用于语文
- 义务教育阶段试卷：教材基准为统编版高中必修与选择性必修，默写篇目核对不适用
- 作文评分与分析：本 Skill 不处理写作题
- 无法获取题干文本的试卷：缺少题干时无法确定考查点
- 需要联网检索真题原文的请求：一律以用户上传材料为准

## 数据与隐私

- 学生答卷只在本次分析中使用，不上传、不外传、不创建副本
- Skill 不建立学生信息档案，不写入任何历史记录文件
- 生成的数据表由用户自行保管，Skill 不指定存储位置之外的路径
- 生成的报告中不写入学生姓名，如需标注请用户自行添加
- 脚本不读取环境变量、Cookie、Token 或任何凭据文件
