历年高考语文试卷分析框架（不含作文）

以"考什么 / 怎么考 / 考得怎么样 / 为什么这么考"四问为主线，客观题抓选项设计、主观题抓设问与采分点 —— 可直接作为教研工具 / 课题研究工具（编码表）使用

适用：高中语文（必修·选择性必修） 学理依据：《中国高考评价体系》《普通高中语文课程标准（2017年版2020年修订）》 版本：v2.0
先定性再动手：分析历年真题本质上属于内容分析（对既有文本进行非介入式编码），所以真正的答案是——先设计一张编码框架，让每道题在同一套字段下被登记。本文件按"四问主线：考什么 / 怎么考 / 考得怎么样 / 为什么这么考"组织，这是索引维度；每一个问题下再落到五层字段，这是真正的编码维度。索引维度与编码维度必须是两套，不能混成一层——这是本框架与常见"8 + 8 角度清单"最关键的区别。

第 0 步 动手前必须先定的三件事

这一步跳过，后面所有统计都不可比——这是真题分析最常见的翻车点。

事项要落定的问题建议口径
① 分析单元 "一道题"指什么？一道大题可能含 2—3 个设问，选项是否单独计入？ 主编码到设问（小题号，如 8 ①）；选项另设子表，按"选项"为单位编码。
② 样本分层 全国甲/乙卷、新课标Ⅰ/Ⅱ卷、自主命题卷命题逻辑不同，混在一起趋势必然失真。 先按卷别 + 年份 + 是否进入新高考三层分组，分组内再谈趋势；跨组只做定性描述。
③ 赋分口径 同一考查点在不同年份分值不同，"题量占比"和"分值占比"是两个结论。 频次与分值双轨统计，凡涉及"重要性"一律用分值占比说话。

一、主框架 四问主线 × 五层字段

为什么要有"四问"："考什么 / 怎么考 / 考得怎么样 / 为什么这么考"是分析目的——它回答"我这次分析究竟要得出什么"。"选项设计""设问与采分点"是抓手，是抓手最锋利的那两处，但抓手不等于维度本身。下面的八层角度是可以真正落表统计的字段。

1.1 四问主线 → 落表字段的对应

四问实质是在问落到的字段产出物
考什么内容与考点覆盖板块 × 文本类型 × 考点 × 教材关联考点频次矩阵、双向细目表
怎么考设问技术与选项技术指令动词 · 限定语 · 选项改写 · 设误类型 · 情境类型 · 评分标准命题技术谱系表
考得怎么样难度与区分度难度值 P · 区分度 D · 得分率 · 空答/满分率 · 高低分组差异难度结构与失分归因
为什么这么考课标导向与趋势四层四翼映射 · 三类情境 · 学业质量水平四 · 年度修订说明依据链 + 趋势结论

1.2 五层字段体系（真正用于编码）

层字段一定要落表的理由
L1 基础属性年份 / 卷别 / 是否新高考 / 题号 / 题型 / 分值 / 板内与全卷占比所有统计的分组变量，缺一层口径就不可比
L2 内容属性板块 / 文本类型 · 体裁 / 选材来源 / 篇幅与信息密度 / 单文本或群文 / 教材关联"考什么"的载体层，也是教考衔接的证据
L3 能力与素养考点（知识）· 指令动词（映射认知层级）· 情境类型 · 实践活动类型 · 四层四翼 · 学业质量水平知识与能力必须双编码，"考比喻"≠"考鉴赏"
L4 命题技术选项改写方式 · 设误类型 · 正确项改写幅度 · 题干限定语 · 答案要点结构 · 评分标准形态 · 开放度最富研究价值、也最常被跳过的一层
L5 测量属性难度 P · 区分度 D · 得分率 · 空答率 · 满分率 · 高低分组选项分布没有这层，"难度与区分度"就只能写定性感受

1.3 本框架与"8 + 8 角度清单"的差异（差异即理由）

对比项常见 8 + 8 角度清单本框架差异为什么重要
组织逻辑 按"客观题 / 主观题"平行罗列八个角度，角度之间基本并列 四问锚定目的 → 五层字段承载统计 → 再分主客观 8 + 8 的"8"是维度，"四问"是目的，两者不在一个层级。混在一起会既锚不住目的，又落不了表
分析单位 未定义"一道题"的边界 主编码到设问，选项另建子表 不定义单位，"题量占比"这类统计前后口径会打架
难度数据 直接要求"通过率、区分度" 双轨：公开卷无官方作答数据时，降级为"结构难度可及性"（作答负荷 + 文本依赖度 + 模板有效性 + 知识点交锋度） 这是 8 + 8 最实操的漏洞——绝大多数老师拿不到 P、D 值，这一栏会整栏空掉
能力层级依据 沿用旧考试大纲的 A 识记 / B 理解 / C 分析综合 / D 鉴赏评价 四层四翼 + 课标素养，旧 ABCD 仅作辅助参照 取消考试大纲后能力层级已无官方效力，直接引用会削弱学理说服力
分析对象边界 客观题含"默写填空"、主观题含"翻译 / 默写"，两边重复 把翻译、默写、语用等填答型题单列为限制作答题（与选择题、采点作答题并列三分） 默写衡量的是精确回忆，被计入选对得分率会直接污染"选择题难度"结论
赋分梯度 "分值梯度（4/6/8 分）与要点数量对应" 只登记实际分值，不预设 4/6/8 分档与"要点数 = 分值 ÷ 2"的换算 套路化换算在近年命题中已不成立，预设会让统计失真
得分率层级 只问"平均分、难度" 区分整题得分率与单点得分率——后者才真正对教学有用 "8 分题平均得 4 分"无法回答学生究竟在哪一个采分点上失分
教学性维度 未单列 新增教考衔接度与教材关联度独立成栏，并区分显性 / 隐性关联 一线教师做真题分析，最想要的抓手就是这个；且近年命题的显性回落是可观测趋势
情境概念层级 把"情境化任务、图文结合、跨文本互证"与课标三类情境混为一谈 统一到课标个人体验 / 社会生活 / 学科认知三类情境 混用会导致同一道题在不同人手里被编成不同类别，编码一致性崩塌

1.4 二分之外：第三种题型（建议单列）

题型类别包含评分机制分析重点
选择题信息类、文学类、文言、古诗、语用选择题唯一答案，全对给分设误类型 · 干扰项吸引力 · 选项改写幅度
限制作答题默写填空、文言翻译逐点给分，答案高度确定篇目分布 · 情境化默写比例 · 翻译赋分点（实词/虚词/句式/文意）
采点作答题简答、分析、赏析、探究、语用主观、图文转换要点 + 质量分层，可有多解设问方式 · 答案要点结构 · 评分标准形态 · 开放度

默写与翻译虽在"形式上"分属主客观两端，但本质同属"受文本和标准答案双重约束"的一类，单列后统计口径才干净：既不会把默写的高得分率误读为"选择题容易"，也不会把翻译的逐点给分当成"采点作答"来分析。

二、整卷宏观层 看结构、看趋势

序号分析角度具体观察点可支撑的结论
1板块分值结构现代文阅读Ⅰ/Ⅱ、古代诗文阅读、语言文字运用、名篇名句默写各占分值，逐年列出板块权重迁移方向（如语用板块压缩、阅读板块扩容）
2主客观题配比选择题分值 ÷ 非选择题分值，逐年曲线是否在推进"减少碎片化选择、增加主观表达"的导向
3题量与阅读量负荷总题数、文本字数、需要书写的作答字数作答负荷变化，能否支撑"减少死记硬背、增加思维容量"的判断
4选材来源报刊/专著/学术论文/文学期刊/官方文献；作者国别、作品年代、是否原创改编选材的时代性、典型性、多样性（课标原文要求）落实情况
5文本类型与体裁信息类（论述文/实用类/非连续性文本）、文学类（小说/散文/戏剧）、文言文（史传/论说/杂记）、古诗（诗/词/曲）文本语体分布是否"角度多样、视野开阔"
6试卷结构与版式稳定性题号顺序、板块顺序、总分、是否有创新呈现形式（如图表、多文本组合）判断命题改革的"小步快跑"节奏
7时间序列趋势至少连续 5—8 年（样本过小不称"趋势"，只能叫"观察"）真正的规律性变化，而非年度偶然
8难度与区分度官方难度值 P、区分度 D、平均分；若无官方数据，用教研机构统计并注明来源难度稳定区间、选拔功能发挥情况
9教材关联度显性关联（直接考课内篇目、作家、单元主题）与隐性关联（能力点对应单元任务）分别登记教考衔接程度——这是最能为一线教学提供抓手的角度
10命题依据映射对照高考评价体系"四层四翼"与课标学业质量水平四逐项归位试卷的"合法性"说明，也是研究报告中必须有的依据链

三、客观题分析层 选择题专项

客观题的分析价值，一半在"考什么"，另一半在"怎么设错"。设错技术分析是很多老师忽略的富矿。

序号分析角度具体观察点 / 编码取值可支撑的结论
1考点分布与频次逐题登记考查点（信息筛选整合、理解分析、推断判断、文言实词、断句、文意概括、语病、衔接、词语运用……），做年份 × 考点频次矩阵高频考点清单 → 直接转化为复习重点
2认知层级题干思维要求分四级：识别确认理解转述推断判断评价鉴赏选择题是否长期停留在低阶识记，或已上探到推断与评价
3题文对应位置选项信息在原文中的落点：句内 → 句间 → 段内 → 跨段 → 全文整合定位难度的变化，反映"检索能力"要求的提高
4选项改写方式原文→选项的加工动作：同义替换 / 概括压缩 / 语序调整 / 增补限定 / 概念替换 / 逻辑关系改写（因果、条件、递进、并列）哪类改写最容易失分 → 训练靶点
5干扰项设误类型八类设误法逐项编码统计：偷换概念、张冠李戴、无中生有、以偏概全、强加因果、混淆时态/模态、曲解文意、答非所问设误法频次表 = 学生"避坑清单"的实证来源
6正确项特征正确项对原文的改写幅度（越小越易）、是否为原文语句的直接转述难度来源是"找得到"还是"看得出来"
7题干限定语"根据原文""推断""最恰当""不符合的一项"等约束性词语的强度与分布答题指令的精确化程度
8选项语言特征绝对化词语（一定、全部、必须）、模态词（可能/必然）、程度副词的分布密度是否存在可被"极端表述避坑法"利用的规律
9干扰项吸引力若可获得作答数据：各选项选择率、低分组/高分组选择差异干扰项是否"真在干扰"，还是形同虚设（区分度分析）
10考点与文本类型耦合信息类文本（筛选+推断为主）、文学类文本（理解+鉴赏为主）、语用题（规范运用为主）分别建模不同文体的应试策略差异有据可依

四、主观题分析层 采点作答题专项

主观题最关键的一步是：不要只看题干，必须把评分细则一起编码。题干告诉你"问什么"，细则才告诉你"真正要什么"。

序号分析角度具体观察点 / 编码取值可支撑的结论
1板块与分值分布各主观题题号、所属板块、分值、赋分梯度哪些板块把"分"押在主观表达上
2题干结构四要素拆解把每道题干拆成：情境/背景 + 指令动词 + 限定范围 + 赋分，对照设问是否"限定越少、开放越大"设问的开放度演变，以及"套模板失效"的机理
3指令动词频次概括、分析、赏析、说明、探究、评价、比较、推断、梳理、拟写……按年统计并映射认知层级（布卢姆 / SOLO）能力要求的重心迁移（如"分析""探究"占比上升）
4情境类型按课标三类情境编码：个人体验情境 / 社会生活情境 / 学科认知情境三类情境的运用是否均衡，学科认知情境是否被低估（当前研究热点）
5语文实践活动类型按课标命题指向编码：阅读与鉴赏（整体感知/信息提取/理解阐释/推断探究/赏析评价）· 表达与交流（叙述表现/陈述阐释/解释分析/介绍说明/应对交流）· 梳理与探究（积累整合/筛选提炼/归整分类/解决问题/发现创新）三大实践活动的分值分布 → 最贴近课标的分析口径
6文本依赖度答案能否完全从文本内部推出（信息自足度），还是需调用外部知识（文学史、文体知识）"反套路化"程度，与学科认知情境关联
7答案要点结构得分点数量、单点分值、要点类型（内容要点 / 手法术语 / 分析论证 / 表达效果 / 情感态度 / 观点评价）、要点是否有层级差把"答案长什么样"变成可统计的模型 → 答分点教学有据
8评分标准形态采点给分（细则式）/ 关键能力分层 / 等级描述 / SOLO 分层 / "言之成理即可"开放评分评分方式与考查目标的匹配度，是命题质量的重要判据
9开放度与答案确定性答案唯一 / 多解并列 / 完全开放，逐年占比开放性探究性试题的落实程度（课标明确要求"多设置主观性、开放性的题目"）
10作答负荷建议字数 / 实际优秀答案字数、书写总量考试时间与思维容量的张力，是否为"时间不够"型失分
11教材关联（教考衔接）与统编教材篇目、单元学习任务、整本书阅读、18 个学习任务群的对应关系教学回归教材的直接证据
12专类专项细分默写：篇目分布、情境化默写比例、必修/选择性必修配比；翻译：实词、虚词、句式、文意的赋分点分布；断句/语言运用：单独建模拆出高确定性、高产出的专项训练清单

五、依据层 为什么这样命题

前文所有统计最终都要归位到两条依据链上，研究报告的"学理说服力"就来自这里。

链条一 · 《中国高考评价体系》

一核立德树人、服务选才、引导教学

四层核心价值、学科素养、关键能力、必备知识（考什么）

四翼基础性、综合性、应用性、创新性（怎么考）

载体情境 —— 承载考查内容、实现考查要求

命题理念：价值引领、素养导向、能力为重、知识为基。

链条二 · 高中语文课程标准

素养语言建构与运用、思维发展与提升、审美鉴赏与创造、文化传承与理解

载体个人体验情境 / 社会生活情境 / 学科认知情境

任务18 个学习任务群；典型任务要"多样、综合、开放"

水平水平二是学业水平考试依据，水平四是高校考试招生录取依据

原则避免单纯知识点、能力点设题，避免死记硬背；试卷结构不应固化

依据来源：教育部《中国高考评价体系》发布说明及《中国考试》相关解读文章；《普通高中语文课程标准（2017年版2020年修订）》"学业质量""学业水平考试与高考命题建议"部分。以上表述为课标与官方解读原文要点，未添加条目编号。

序号典型问题修正做法
1没定义分析单元就开始统计，"题量"口径前后不一先落定第 0 步的三件事，全表口径唯一
