# 高中语文试卷与答卷分析

一个 WorkBuddy Skill：按「四问主线 × 五层字段」编码高中语文试卷，得出它的考查范围；再与学生答卷逐题比对，判定该生的优势与劣势。

## 它解决什么问题

手工分析一套卷子，常见的困境是：翻来覆去看得出"考了默写、考了赏析"，但说不出**权重怎么分布、覆盖哪里有缺口**；学生答完卷，只知道"这里扣了分"，说不出**是知识不会还是表达不成型**。

这个 Skill 把分析过程变成一套可复用的编码框架与固定输出，让每次分析的结论都能互相比较。

## 核心框架

### 四问主线（分析目的）

| 四问 | 实质是在问 | 产出物 |
|---|---|---|
| 考什么 | 内容与考点覆盖 | 考点频次矩阵、双向细目表 |
| 怎么考 | 设问技术与选项技术 | 命题技术谱系表 |
| 考得怎么样 | 难度与区分度 | 难度结构与失分归因 |
| 为什么这么考 | 课标导向与趋势 | 依据链与趋势结论 |

### 五层字段（编码维度）

| 层 | 字段 |
|---|---|
| L1 基础属性 | 年份、卷别、题号、题型、分值、占比 |
| L2 内容属性 | 板块、文本类型、体裁、选材来源、教材关联 |
| L3 能力与素养 | 考点、指令动词、认知层级、情境类型、实践活动 |
| L4 命题技术 | 选项改写、设误类型、答案要点结构、评分标准、开放度 |
| L5 测量属性 | 难度、区分度、得分率、失分机理 |

## 三个关键设计

**1. 题型三分，而不是主客观二分**

选择题 / 限制作答题（默写·翻译）/ 采点作答题。默写与翻译单列，避免默写的高得分率污染"选择题难度"的统计。

**2. 同分不同病**

两名学生同得 4 分（满分 8），一个可能是"命中 2 个采分点、其余空白"，另一个是"4 个点都碰到但都不完整"。前者是知识空缺，后者是表述不成型——**补强方向相反**。这个 Skill 强制分开表述。

**3. 证据等级标注**

| 等级 | 条件 | 允许的结论强度 |
|---|---|---|
| A 已核验 | 有评分细则且答卷可清晰识别 | 可给精确分，可做单点失分分析 |
| B 部分验证 | 有答案无细则，或部分字迹模糊 | 给区间分，模糊处标待确认 |
| C 推断 | 仅有总分或等级 | 只做板块层面粗判 |
| D 未验证 | 关键内容无法辨认 | 不出结论，只列待确认项 |

报告里每个结论后面都要挂这个等级。手写答卷不靠猜——看不清就标出来问你。

## 怎么用

在 WorkBuddy 中安装后，对着它说话即可：

- 「分析一下这份卷子」
- 「这份卷子考了哪些知识点」
- 「看看这答题卡这学生问题在哪」
- 「把月考卷和学生答卷一起分析」
- 「这学生哪个板块最弱」

它会先问你本次要做哪件事（只看考查范围 / 只看学生答卷 / 两者都要），再往下跑。

### 输入

- **试卷**：PDF（含文字层）、图片、Word、纯文本
- **答卷**：扫描图或照片（手写）、电子文本、表格
- **评分细则**：有则证据等级升到 A，没有则只判要点方向

### 输出

- 分析报告（加强版，含补强建议）
- 数据表 xlsx：逐题编码表、学生得分对照表、双向细目表

## 未覆盖范围

- 只做高中语文，字段词表与考点分类不适用于其他学科
- 只覆盖统编版必修与选择性必修，义务教育阶段默写篇目核对不适用
- 不处理作文
- 不联网检索真题原文
- 不替学生作答，不给应试话术

## 学理依据

- 《中国高考评价体系》：一核（立德树人、服务选才、引导教学）、四层（核心价值、学科素养、关键能力、必备知识）、四翼（基础性、综合性、应用性、创新性）、考查载体为情境
- 《普通高中语文课程标准（2017年版2020年修订）》：三类语文实践活动情境（个人体验情境、社会生活情境、学科认知情境）、三大语文实践活动及命题指向（阅读与鉴赏、表达与交流、梳理与探究）、学业质量水平四为高校招生录取依据
